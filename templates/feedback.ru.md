Шаблон отправляемого блока файла ревью, язык ru.

Назначение. Судья пишет части текста без разметки (feedback_parts в JSON), рендер собирает
из них отправляемый блок по этому шаблону и проверяет запреты текста (раздел «Проверки
скриптом» в references/output-contract.md). Шапку-комментарий рендер вырезает, адресату она
не уходит. Свой шаблон workspace кладётся в .retropair/templates/feedback.md, выбор
файла делает параметр feedback.template карточки. Плейсхолдеров ровно пять, других нет.

Плейсхолдеры:
- {{prefix}}   строка feedback.prefix из карточки как есть; пустая строка → строка шаблона
               удаляется вместе с пустой строкой после неё.
- {{opening}}  feedback_parts.opening одним абзацем.
- {{actions}}  пункты feedback_parts.actions по порядку, каждый одним абзацем по формату
               ниже, между пунктами пустая строка.
- {{criteria}} восемь строк feedback_parts.criteria в порядке осей, формат ниже, между
               строками пустая строка.
- {{closing}}  feedback_parts.closing одним абзацем; null → строка шаблона удаляется.

Заголовок блока с периодом (period.label) в шаблон не входит: рендер ставит его строкой над
блоком. Баллов, уровней и кодов осей в шаблоне нет; баллы и уровень показывает личный
HTML-отчёт по настройке show_scores, а не шаблон.

Пункт действия (один абзац, одна строка без переносов):
**<n>.** <date>, <place>: «<quote>»; <cost>. Стоит попробовать: <try>. Соседний рычаг: <lever>.
- <n>: Первое, Второе, Третье по индексу пункта;
- <date>: дата словами, «12 марта»; date = null → «<date>, » опускается, и первая буква
  <place> становится заглавной;
- <quote> в кавычках-ёлочках как есть, внутри цитаты ничего не правится;
- поле без своей конечной точки получает точку от рендера;
- «Соседний рычаг: <lever>.» повторяется по разу на каждый элемент levers (0–2); пустой
  levers → хвоста нет.

Строка критерия (одна строка):
**<axis name>.** <verdict> <evidence>
- <axis name>: axes.<axis>.ru из i18n.json, жирным только имя;
- <verdict>: verdicts.<verdict>.ru из i18n.json, не выделяется;
- <evidence> как есть; пустая строка → строка кончается на <verdict>.

Режим short (feedback.length: short): форма шаблона та же, все пять частей и восемь
критериев на месте. Судья пишет короче: вступление одной фразой, не больше двух пунктов
действий, рычагов ноль, у критерия вердикт плюс одна фраза с адресом. Рендер это проверяет
и не обрезает молча: больше двух пунктов или хотя бы один рычаг → ошибка с названием
условия. feedback.practices: false убирает рычаги так же, как short.
