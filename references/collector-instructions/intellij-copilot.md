# IntelliJ IDEA (или другой JetBrains) плюс GitHub Copilot

Честно с самого начала: эта связка не прогонялась. Плагин Copilot внутри JetBrains
не выкладывает историю чата обычными файлами, и автоматического сборщика для него сейчас
нет: SpecStory поддержку Copilot только разрабатывает. Пока путь один — ручной, и он
рабочий, просто требует дисциплины.

## Шаг 1. Заведите папку для логов и подключите её

```bash
cd путь/к/проекту
mkdir -p ai-logs
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/sr.py" init --mode self
```

Последняя команда нужна один раз, если workspace ещё нет. В `.sessionretro/config.json`
в поле `sources` добавьте папку:

```json
"sources": [
  {"type": "dir", "path": "ai-logs"}
]
```

Сделайте это заранее, чтобы не собирать всё в последний вечер.

## Шаг 2. После каждой заметной сессии сохраните переписку

Закончили работу над задачей — выделите переписку с агентом в панели, скопируйте её
и сохраните в файл внутри `ai-logs/`, например `ai-logs/session-2026-01-15.md`. Одна
сессия — один файл, в имени дата. Роли размечайте заголовками, а дату — строкой `Date:`,
тогда sessionretro разберёт ходы:

```markdown
Date: 2026-01-15

## User
текст запроса

## Assistant
ответ агента
```

Копируйте переписку по этому проекту, а не всё подряд: рабочие диалоги по другим
проектам уезжать никуда не должны.

## Шаг 3. Соберите и вычистите

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/sr.py" collect
```

При ручном копировании никакой встроенной вычистки нет вообще, поэтому этот шаг
обязательный. Команда копирует каждый файл снимком в `.sessionretro/logs/me/` и по дороге
вычищает его встроенным санитайзером: секреты, пароли, почту, телефоны, строки
подключения, имя пользователя ОС в путях. Файлы в `ai-logs/` не меняются, `*.orig`
плагин не пишет.

Имена собственные регулярным выражением не ловятся, это единственное, что нельзя закрыть
автоматически. Впишите свои названия и фамилии — компанию, коллег, внутренние системы —
в `.sessionretro/config.json`:

```json
"sanitize": {"names": ["ООО Ромашка", "Иванов"], "extra_patterns": []}
```

Вызовы инструментов в ручной выгрузке не размечены, поэтому метрики по командам агента
и по контекстному окну для этой связки не считаются.

## Шаг 4. Посмотрите своими глазами

```bash
grep -rn "REDACTED\|SECRET_ASSIGNMENT\|API_KEY\|EMAIL\|PHONE\|NAME" .sessionretro/logs | head
```

Затем откройте один снимок и пролистайте: автоматика ловит форматы, а название клиента
в свободном тексте видите только вы. В переписку попадает содержимое файлов, которые
агент читал, то есть ваш код.

## Если логи смотрит другой человек

Ревьюер собирает логи из вашего приватного репозитория. Отдавайте уже вычищенные снимки,
а не сырую папку `ai-logs`:

```bash
git add .sessionretro/logs
git commit -m "логи сессий"
git push origin
```

## Если что-то не сходится

Эту связку проверить было не на чем. Если что-то пойдёт иначе — панель не даёт выделить
переписку целиком, история куда-то пишется файлами, что угодно — откройте issue
в репозитории плагина, инструкцию поправят.

В сводке `collect` у файла ноль ходов. Проверьте разметку ролей: заголовки `## User`
и `## Assistant` на отдельных строках.
