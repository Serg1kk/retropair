# Visual Studio (.NET)

Честно с самого начала: эта связка не прогонялась. Автоматические сборщики логов с Visual
Studio не работают: все они рассчитаны на терминальных агентов и на редакторы семейства
VS Code, а Visual Studio устроена иначе. К тому же Visual Studio — это Windows, а SpecStory
под Windows нет, и сбор RetroPair на Windows в 0.2 не поддерживается.

Поэтому путь ручной, и он подробно расписан в соседнем файле [windows.md](windows.md):
экспорт переписки в конце каждой сессии, сбор и вычистка на macOS или Linux. Откройте его
и идите по шагам.

Два уточнения именно под этот случай.

Первое. Если ваш агент работает панелью внутри Visual Studio и команды экспорта у него
нет — копируйте переписку из панели руками в файл `ai-logs\session-2026-01-15.md`
с разметкой ролей, как в [windows.md](windows.md), дальше всё без изменений.

Второе. Вариант получше: агента можно запускать не из панели IDE, а из обычного терминала,
открытого в папке проекта, — например Claude Code в PowerShell. Код продолжаете писать
в Visual Studio, меняется только то, откуда стартует агент. Тогда сырые сессии пишутся
автоматически, у Claude Code есть `/export`, и метрики контекстного окна тоже соберутся.

Если что-то не сойдётся на любом шаге, откройте issue в репозитории плагина.
