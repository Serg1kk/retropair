# Windows

SpecStory существует только под macOS и Linux, а сам `rp.py collect` на Windows в 0.2
не поддерживается: блокировка файлов, на которой держится сбор, там не работает. Поэтому
на Windows путь ручной: переписку экспортируете вы, а сбор и вычистка идут на машине
с macOS или Linux — вашей или ревьюера.

Честно про степень проверенности: механика ручного экспорта прогнана на живой сессии,
но не на Windows. Не проверены именно Windows-детали: точный вид диалога `/export`
и команды PowerShell. Если что-то не сойдётся, откройте issue в репозитории плагина.

## Шаг 1. Экспортируйте сессию в конце работы

В Claude Code есть команда `/export` — наберите её в конце сессии и сохраните переписку
в файл внутри проекта, в папку `ai-logs\`, например `ai-logs\session-2026-01-15.md`.
Одна сессия — один файл. Если у вашего агента команды экспорта нет, скопируйте переписку
из панели руками в такой же файл и разметьте роли заголовками, а дату — строкой `Date:`:

```markdown
Date: 2026-01-15

## User
текст запроса

## Assistant
ответ агента
```

Заведите привычку делать это в конце каждой рабочей сессии. Если агент — Claude Code,
в `ai-logs\` можно положить и сырые файлы сессий `.jsonl` из
`%USERPROFILE%\.claude\projects\<папка проекта>\`: по ним считаются метрики контекстного
окна. Claude Code удаляет их примерно через тридцать дней, так что не тяните.

## Шаг 2. Посмотрите файлы сами

До сбора файлы в `ai-logs\` не вычищены: санитайзер работает там, где запускают
`collect`. Пролистайте их перед тем, как переносить: пароли, ключи, названия клиентов,
фамилии. В лог попадает содержимое файлов, которые агент читал, то есть ваш код.

## Шаг 3. Соберите на macOS или Linux

**Проверяете себя.** Перенесите проект с папкой `ai-logs` на машину с macOS или Linux
и там, в корне проекта, один раз создайте workspace и подключите папку:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/rp.py" init --mode self
```

```json
"sources": [
  {"type": "dir", "path": "ai-logs"}
]
```

Затем соберите:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/rp.py" collect
```

Команда копирует каждый файл снимком в `.retropair/logs/me/` и по дороге вычищает его
встроенным санитайзером. Свои названия и фамилии впишите в `.retropair/config.json`:

```json
"sanitize": {"names": ["ООО Ромашка", "Иванов"], "extra_patterns": []}
```

**Логи смотрит ревьюер.** Закоммитьте `ai-logs` в свой приватный репозиторий
из PowerShell:

```powershell
git add ai-logs
git commit -m "логи сессий"
git push origin
```

Ревьюер подключит репозиторий источником `git` и соберёт логи у себя, санитайзер отработает
при его сборе. До этого файлы лежат в репозитории как есть, поэтому шаг 2 не пропускайте,
а репозиторий держите приватным.
