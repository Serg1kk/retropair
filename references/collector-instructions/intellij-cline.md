# IntelliJ IDEA (или другой JetBrains) плюс Cline

Честно с самого начала: эта связка не прогонялась, и SpecStory Cline не поддерживает.
Зато Cline, в отличие от многих, хранит свои задачи обычными файлами на диске, так что
историю найти можно всегда.

Одна оговорка: задачи Cline лежат в формате `.json`, а его RetroPair 0.2 не разбирает.
Поэтому переписку задачи надо сохранить в markdown — из панели Cline или вручную.

## Шаг 1. Найдите, где лежат ваши задачи

Cline складывает каждую задачу отдельной папкой с историей сообщений. Выполните:

```bash
find ~ -maxdepth 6 -type d \( -name "tasks" -path "*cline*" -o -name "tasks" -path "*claude-dev*" \) 2>/dev/null | head
```

Если ничего не нашлось, поищите шире:

```bash
find ~ -maxdepth 6 -type d -iname "*cline*" 2>/dev/null | grep -v Trash | head
```

Внутри найденной папки должны быть подпапки с номерами и файлы вида
`api_conversation_history.json` и `ui_messages.json`. Это и есть ваши логи.

Сделайте эту проверку **до начала работы**, а не после: если у вашей сборки всё устроено
иначе, лучше узнать об этом заранее. Свежая метка времени у файлов после пяти минут
работы с агентом означает, что история пишется.

## Шаг 2. Заведите папку для логов и подключите её

```bash
cd путь/к/проекту
mkdir -p ai-logs
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/rp.py" init --mode self
```

Последняя команда нужна один раз, если workspace ещё нет. В `.retropair/config.json`
в поле `sources` добавьте папку:

```json
"sources": [
  {"type": "dir", "path": "ai-logs"}
]
```

## Шаг 3. После работы сохраните нужные задачи

Задачи лежат по времени изменения, поэтому свежие видно сразу:

```bash
ls -lt <найденный-путь-к-tasks> | head -5
```

Для каждой задачи по этому проекту сохраните переписку в `ai-logs/` — одна задача,
один файл, например `ai-logs/session-2026-01-15.md`. Если панель Cline умеет экспорт
в markdown, используйте его; иначе скопируйте переписку и разметьте роли заголовками,
а дату — строкой `Date:`:

```markdown
Date: 2026-01-15

## User
текст запроса

## Assistant
ответ агента
```

Сохраняйте именно задачи по этому проекту, а не всё подряд: в общей папке лежат и другие
рабочие задачи, они уезжать никуда не должны.

## Шаг 4. Соберите и вычистите

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/rp.py" collect
```

Этот шаг обязательный: никакой встроенной вычистки у Cline нет, файлы лежат как есть.
Команда копирует каждый файл снимком в `.retropair/logs/me/` и по дороге вычищает его
встроенным санитайзером. Файлы в `ai-logs/` не меняются, `*.orig` плагин не пишет.

Имена собственные регулярным выражением не ловятся. Впишите свои названия, фамилии
и внутренние системы в `.retropair/config.json`:

```json
"sanitize": {"names": ["ООО Ромашка", "Иванов"], "extra_patterns": []}
```

Отдельно посмотрите глазами хотя бы один снимок:

```bash
grep -rn "REDACTED\|SECRET_ASSIGNMENT\|API_KEY\|EMAIL\|PHONE\|NAME" .retropair/logs | head
```

В историю Cline попадает содержимое файлов, которые агент читал, то есть ваш код, и раз
это рабочая машина, там может оказаться лишнее.

## Если логи смотрит другой человек

Ревьюер собирает логи из вашего приватного репозитория. Отдавайте уже вычищенные снимки,
а не сырую папку `ai-logs`:

```bash
git add .retropair/logs
git commit -m "логи сессий"
git push origin
```

## Если что-то не сходится

Эта инструкция собрана по устройству инструмента, а не по прогону. Если папка задач
не нашлась или внутри оказалось не то, что описано, откройте issue в репозитории плагина
и приложите вывод команд из первого шага.

В сводке `collect` у файла ноль ходов. Проверьте разметку ролей: заголовки `## User`
и `## Assistant` на отдельных строках.
