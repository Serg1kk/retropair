# Тестирование sessionretro

## Как запускать тесты

Команды — из корня плагина (папка с `.claude-plugin/`).

- Юнит-тесты (python ≥ 3.10, только stdlib):
  `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts/tests -v`
- Один файл тестов: `cd scripts/tests && PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_people`
- Проверка манифестов хостом: `claude plugin validate .`
- Состав плагина: `claude --plugin-dir . plugin details sessionretro` — 4 скилла, 3 агента.
- Гейты чистоты (в репозитории разработки, вне плагина, из его корня; путь к плагину —
  абсолютный): `python3 tools/gates.py "$(pwd)/plugin"`; их собственные тесты и тесты
  релиза: `python3 -m unittest discover -s tools/tests -v`.

## Общие правила тестов

- Тесты не пишут ни в папку плагина, ни в настоящий домашний каталог. Всё — во временные
  папки; `HOME` подменяется (`TempHome` и `run_sr(..., home=…)` в `scripts/tests/_util.py`).
- CLI проверяется отдельным процессом (`run_sr`): код выхода, stdout и текст ошибки в stderr.
  Коды: `0` — ок, `1` — данные/проверка, `2` — неверный вызов.
- Фикстуры лежат в `scripts/tests/fixtures/`, в них только вымышленные люди и пути
  `/home/user/…`. Тест копирует фикстуру во временную папку (`copy_fixture`) и не меняет
  оригинал.
- Каждый скрипт приходит с тестами в том же изменении: синтетические данные, тест на каждую
  ветку проверки и хотя бы один тест на реальном файле плагина (шаблоне, схеме, документации).
- Тесты плагина не ссылаются ни на что вне папки плагина: плагин работает, вынутый из
  репозитория разработки.
- Необязательные внешние программы (`claude`, `specstory`) отсутствуют — тест или гейт
  пропускается с видимой строкой `skip`, а не падает.

## Каркас: CLI, состояние, карточки

Фикстура `scripts/tests/fixtures/workspace-min/` — готовый workspace для тестов любых команд:
режим `team`, группы `team-a` и `team-b`, карточки `alex` и `sam` (вымышленные),
`people/_default.yaml`, `plugin-state.json`. Использование:

```python
from _util import copy_fixture, run_sr
root = copy_fixture("workspace-min", tmp)          # tmp — временная папка теста
res = run_sr("people", "list", "--workspace", str(root), home=home, cwd=tmp)
```

python3 "${CLAUDE_PLUGIN_ROOT}/scripts/sr.py" init --mode team --title "Demo"

python3 "${CLAUDE_PLUGIN_ROOT}/scripts/sr.py" people context alex
