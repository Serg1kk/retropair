# Roadmap

Что есть в sessionretro, что проверено и что будет дальше. Строки нет — значит, не проверяли.

## Сделано и проверено на Claude Code (0.1)

- Три режима из одного кода: self (проверяю себя), team (ревьюер смотрит команду), course
  (преподаватель смотрит учебную группу).
- Настройка диалогом `/sessionretro:setup` до 11 вопросов и без диалога `setup-apply --answers`.
- Сбор логов Claude Code напрямую, выгрузок SpecStory, папок и git-репозиториев; санитайзер
  обязателен; фоновый сбор хуком SessionEnd по желанию.
- Оценка в две ступени по восьми осям поведения: сборщики по пачкам без баллов, один оценщик;
  оценка только под цитату, иначе «мало данных»; уровень по формуле.
- Личный текст с одним-тремя шагами-действиями, проверка прошлых рекомендаций в следующем
  периоде, одобрение ревьюером в team и course.
- Локальные самодостаточные HTML-отчёты: ревьюера, групповой, личный, страница всех workspace;
  защита от чужих имён в личных файлах, обезличенная копия `--anon`.
- Карточки людей, заменяемый шаблон текста, проектные агенты с выбором модели и effort.
- Эталонный набор из 15 сессий для проверки оценщика; обезличенный демо-workspace.

## Сбор логов других агентов

Логи Cursor, Codex, Antigravity CLI и других агентов, которые выгружает SpecStory (например,
Gemini CLI), собираются через неё или ручной экспорт в папку; оценка запускается из Claude Code.
Проверенность каждой связки — в [инструкциях по связкам](references/collector-instructions/README.md).

## Известные ограничения 0.1

- Windows: сбор логов и блокировка файлов не работают; путь — ручной экспорт и сбор на macOS
  или Linux.
- Файлы сессий Codex и Cursor в их собственном формате напрямую не читаются: только
  предупреждение, путь — SpecStory.
- Референсы осей только на русском; английский текст оценщика не проверялся на эталонном наборе.
- Санитайзер не вычищает имена людей, упомянутых внутри лога, если их нет в карточках и в
  `sanitize.names` ([docs/ru/privacy.md](docs/ru/privacy.md)).
- Claude Code хранит свои логи 30 дней по умолчанию (`cleanupPeriodDays`); сессии старше срока,
  не собранные до удаления, в ретро не попадут.
- `claude-jsonl` с `auto` находит сессии, открытые из корня проекта, но не из подпапок.
- Отчёт ревьюера на большой группе тяжёлый: 20 человек за шесть периодов — около 3 МБ.

## В планах

- Запуск оценки из Codex и Cursor.
- Чтение файлов сессий Codex и Cursor напрямую, без SpecStory.
- Windows: сбор и блокировка файлов.
- Английские референсы осей и проверка английского текста на эталонном наборе.
- Группы в интерфейсе отчётов.
- Серверный вариант интерфейса для команды.
- Карточка-итог периода, которой удобно поделиться.
- Медиа в отчётах.

## Не делаем

- Рейтинги и лидерборды людей.
- Аналитику токенов и денег: для этого есть трекеры расхода.
- Ревью кода и оценку результата работы.
- Сравнения людей между собой: каждый сравнивается только со своим прошлым.
